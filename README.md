============================================================================================================

Unlike most melon DS ports this one comes fully optimized, with an amazing frontend UI and usable on mobile, desktop, or the xbox x/s browser! games can be played with controllers and WITH NO BIOS needed. since this core uses freebios. meaning that it uses high level emulation in an interpreter system to play most DS and DSI games without a provided BIOS or firmware.

============================================================================================================
*This core does NOT come with any games, you must provide your own!*
# The Library creator
This project is highly based on webRcade, so that means it has its own .Json feed system!
with the library creator in the main menu you can create lists of games, set the url for their .nds or .dsi file, and a url for the carts icon, and a short description of your game then you can export your list as a .Json. then back in your library tab you can choose to load a .Json locally or from a URL *(you see how this is setup exactly for Xbox right?)*
